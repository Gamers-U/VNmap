# Карта новеллы — версия для компьютера

Та же программа, что и в браузере, но в собственном окне: проекты сохраняются в обычные файлы `.vnmap`,
игра собирается сразу в папку, а проект и все загруженные картинки и звуки можно хранить на Google Диске
и открывать на другом компьютере.

## Как запустить

Нужен [Node.js](https://nodejs.org) 20 или новее.

```
cd desktop
npm install
npm start
```

Страницу программы собирает `python3 ../build.py` (она кладёт её в `desktop/app/index.html`; готовая версия уже лежит).

### Готовые установщики

```
npm run dist:win      # установщик и портативный .exe (на Windows)
npm run dist:mac      # .dmg и .zip (только на Mac)
npm run dist:linux    # AppImage
```

Результат появится в `desktop/release/`. Windows может показать предупреждение SmartScreen: программа не подписана
сертификатом. «Подробнее» → «Выполнить в любом случае». Для macOS без подписи при первом запуске
нужно открыть программу через правую кнопку → «Открыть».

### Windows без установки Node.js и Python

Распакуйте архив с исходниками и запустите `desktop\install-windows.bat` (двойной щелчок). Скрипт скачает официальный Electron
(с проверкой контрольной суммы) и соберёт готовую папку `VNMap` с `VNMap.exe`. Нужен только интернет. Скрипт написан по документации
PowerShell и на Windows ещё не запускался автором: если он споткнётся, сообщите текст ошибки.

### Портативная версия без npm

```
python3 pack.py                # Windows x64 и Linux x64
python3 pack.py win-arm64
```

Скрипт скачивает официальный Electron (с проверкой контрольной суммы), кладёт в него программу и собирает архив
в `desktop/release-portable/`. Установщиков и значка в `.exe` такой способ не делает: для них нужен `npm run dist`.

## Что умеет настольная версия

- **Файлы проектов `.vnmap`.** Ctrl+S сохраняет в привязанный файл, Ctrl+Shift+S — «Сохранить как…». Если у проекта есть картинки и звуки,
  файл `.vnmap` — это ZIP со всем содержимым, иначе — обычный JSON. После привязки проект автосохраняется через пару секунд после правки.
  Двойной щелчок по `.vnmap` открывает проект в программе.
- **Сборка игры в папку** (Ctrl+B → «Записать в папку…»). Программа пишет файлы Ren'Py прямо в выбранную папку и убирает те,
  что сама создала при прошлой сборке, но больше не нужны. Чужие файлы в этой папке не трогает.
- **Стартовый экран** при запуске: «Новый проект», «Открыть…», демо-проект, «Продолжить» (проект, который был открыт в программе)
  и список недавних проектов. Меню «Файл» → «Стартовый экран…» (Ctrl+Shift+H) открывает его в любой момент. Выключается переключателем
  внизу экрана. Двойной щелчок по файлу `.vnmap` обходит стартовый экран. Перед заменой проекта, который не записан в файл, программа спросит.
  Ключ `--no-launcher` в ярлыке отключает стартовый экран совсем.
- **Обновление без переустановки** (кнопка «Обновить программу…» на стартовом экране или «Справка» → «Обновить программу…»). Подробно ниже.
- **Google Диск** (меню «Файл» → «Google Диск…»). Подробно ниже.

## Обновление без переустановки

Вся программа, то есть карта, редактор, компилятор и все окна, это одна страница `index.html`. Оболочка (Electron) меняется редко.
Поэтому обновление — это новая страница, которую оболочка кладёт в папку данных и показывает вместо встроенной.

**Как обновить:**

1. Получите файл `vnmap-update-ГГГГММДД.ЧЧММ.zip` (его присылает автор программы; его же делает `python3 build.py` в папке `dist/`).
2. «Обновить программу…» → «Выбрать файл обновления…». Программа проверит файл и покажет сборку, размер и контрольную сумму.
3. «Установить и перезапустить». Окно перезагрузится, проекты и настройки остаются на месте.

Вместо ZIP подойдёт и сам `index.html`. Скачать обновление можно и по ссылке (`https://…`): на ZIP, на `index.html`, на небольшой файл-указатель
`{ "url": "vnmap-update.zip", "sha256": "…" }` или на страницу репозитория GitHub (`https://github.com/автор/репозиторий`: берётся файл `vnmap-update-….zip`
из последнего выпуска). Если автор указал контрольную сумму sha256, её можно вписать в поле «Контрольная сумма».

**Защита:**

- Файл проверяется до установки: размер, отметка сборки в начале страницы, при наличии `update.json` в архиве сверяется контрольная сумма.
  Ссылки принимаются только `https://`.
- Встроенная версия никогда не удаляется. «Вернуть встроенную» убирает установленное обновление одним щелчком.
- Если обновлённая страница при запуске не дошла до связи с оболочкой (например, сломана), при следующем запуске программа сама вернёт встроенную версию и скажет об этом.
- Обновление выполняется внутри программы с теми же правами, что и сама программа: доступ к вашим проектам и к Google Диску. Ставьте только то, что получили от автора.
  Электронной подписи обновлений пока нет: источник вы подтверждаете сами.
- Если обновлению нужна более новая оболочка (в его отметке `data-needs`), программа откажется его ставить и попросит переустановить себя один раз.

**Что обновление не меняет:** саму оболочку (`main.js`, `preload.js`: окна, меню, диалоги, вход в Google). Когда меняются они, нужна переустановка.
Версия 1.1.0 как раз добавила в оболочку стартовый экран и обновление, поэтому её нужно поставить один раз «обычным» способом, дальше обновления идут через кнопку.

## Google Диск

Что делает:

- хранит проект и все загруженные файлы на вашем Диске, в папке `Карта новеллы/<название проекта>/`;
- отправляет правки автоматически, через несколько секунд после последнего изменения;
- раз в выбранное время (по умолчанию 30 минут, при правках) кладёт копию проекта в папку `backups`; старые копии уходят в корзину Диска;
- на другом компьютере показывает список проектов с Диска. Выбираете нужный, и он открывается вместе со всеми картинками и звуками;
- сам подтягивает правки, сделанные на другом устройстве;
- если проект изменили на двух устройствах одновременно, **ничего не затирает молча**: спрашивает, какую версию оставить,
  а вторую сохраняет в `backups`.

Программа получает доступ только к тем файлам, которые создала сама (область `drive.file`). Остальной Диск ей не виден.

### Один раз: получить ключ доступа

Google требует, чтобы у каждой программы был свой ключ. Он бесплатный, делается за несколько минут:

1. Откройте <https://console.cloud.google.com/projectcreate> и создайте проект (название любое).
2. Включите для него «Google Drive API»: <https://console.cloud.google.com/apis/library/drive.googleapis.com>.
3. Откройте «Google Auth Platform» (раньше «Экран согласия OAuth»): <https://console.cloud.google.com/auth/overview>. Тип аудитории — «Внешний», название любое, почта для связи — ваша.
4. На странице «Аудитория» нажмите **«Опубликовать приложение»**. Если оставить статус «Тестирование», Google будет сбрасывать вход каждые 7 дней.
   При первом входе Google может написать, что приложение не проверено: выберите «Дополнительно» → «Перейти». Это ваше собственное приложение.
5. В разделе «Клиенты» (<https://console.cloud.google.com/auth/clients>) создайте клиент типа **«Приложение для ПК» (Desktop app)**
   и скопируйте идентификатор клиента и секрет.

Затем в программе: «Файл» → «Google Диск…», вставьте идентификатор и секрет, «Сохранить ключ», «Войти через Google».
Откроется браузер: подтвердите доступ, и вкладку можно закрыть.

На втором компьютере введите **те же** идентификатор и секрет и войдите в тот же аккаунт Google. Либо положите файл `google-oauth.json`
рядом с `main.js` (пример: `google-oauth.example.json`), и программа возьмёт ключ оттуда. Тогда вводить ничего не придётся,
а `pack.py` и `npm run dist` включат этот файл в сборку.

### Как пользоваться

1. «Файл» → «Google Диск…» → включите «Хранить проект и файлы на Google Диске». Начнётся первая отправка.
2. В строке состояния внизу появится плашка «Диск: синхронизировано». Если что-то не так («нет связи», «нужен вход», «конфликт версий»), она об этом скажет.
3. На другом устройстве: «Файл» → «Google Диск…» → «Проекты на Диске» → «Открыть». Дальше оба устройства синхронизируются сами.
4. Если случайно испортили проект: в том же окне «Копии проекта на Диске» → «Вернуть». Перед возвратом текущая версия тоже сохраняется как копия.

### Что важно знать

- Положение и масштаб карты на экране на Диск не отправляются (иначе каждый сдвиг холста считался бы правкой), поэтому на каждом устройстве вид свой.
- Синхронизация работает только пока программа запущена. Без интернета правки копятся и уходят, когда связь вернётся.
- Крупные файлы (больше нескольких МБ) загружаются частями: на медленном соединении первая отправка может занять время, прогресс виден на плашке.
- Разрешение хранится на компьютере в зашифрованном виде (средствами системы: Windows DPAPI, macOS Keychain, Linux keyring).
  Если у системы нет хранилища паролей, оно лежит в файле с доступом только для вас, и программа об этом предупреждает.
  Отозвать доступ в любой момент можно в настройках аккаунта Google или кнопкой «Выйти».

## Где лежат данные программы

| Что | Где |
| --- | --- |
| Недавние проекты (`recent.json`), установленное обновление страницы (`app-update/`) | рядом с настройками |
| Настройки окна, ключ и вход в Google | Windows `%APPDATA%\VNMap`, macOS `~/Library/Application Support/VNMap`, Linux `~/.config/VNMap` |
| Рабочая копия проекта и загруженные файлы | во внутреннем хранилище программы (рядом с настройками) |
| Ваш проект | файл `.vnmap`, который вы сохранили сами |

Рабочая копия не заменяет файл `.vnmap` и копии на Диске: держите хотя бы один из этих двух способов включённым.

## Как устроен код

| Файл | Назначение |
| --- | --- |
| `main.js` | главный процесс: окно, меню, диалоги, запись файлов, обращения к Google |
| `preload.js` | безопасный мост между окном и главным процессом (`window.vnDesktop`) |
| `gdrive.js` | вход в Google (OAuth, PKCE), хранение токена, запросы к Drive API |
| `renpy.js` | запуск настоящего Ren'Py: проверка папок SDK и проекта, команды `run` / `lint` / `distribute` из белого списка, потоковый вывод (чистый Node, без Electron) |
| `buildwrite.js` | запись собранной игры в папку: безопасные пути, манифест, чистка устаревших файлов и `.rpyc` (чистый Node) |
| `selfupdate.js` | обновление самой оболочки с GitHub: проверка выпуска, скачивание с проверкой SHA-256, установка (Windows-установщик, Linux AppImage) или показ файла (portable, macOS); чистый Node |
| `notify.js` | уведомления в Telegram и Discord: токен бота и ссылка вебхука хранятся зашифрованными, разрешены только `api.telegram.org` и вебхуки Discord, отправка, поиск чата, «прощальное сообщение» при закрытии окна |
| `updater.js` | обновление страницы: разбор ZIP/HTML, проверки, установка, откат (чистый Node, без Electron) |
| `../src/desktop.js`, `../src/drive.js` | поведение в окне: сохранение, синхронизация, копии, конфликты |

Страница работает под собственным протоколом `vnmap://app` с жёсткой политикой безопасности (CSP): сайты оттуда недоступны,
а все обращения к диску и сети идут только через главный процесс.
