## Карта новеллы 1.3.0

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Что нового**
- **Запуск и сборка в настоящем Ren'Py** («Сборка» → вкладка «Запуск в Ren'Py», только в программе для компьютера). Один раз указываете папку Ren'Py SDK и папку проекта, который создал лаунчер Ren'Py. Дальше:
  - «Запустить игру» собирает игру, записывает её в папку проекта (трогает только изменившиеся файлы и убирает устаревшие вместе с их `.rpyc`) и запускает настоящий движок; можно начать с любого блока, остановить или перезапустить;
  - «Проверить (lint)» запускает проверку самого Ren'Py;
  - «Собрать дистрибутив» делает архивы для Windows, Linux, macOS или магазинов;
  - вывод движка виден прямо в окне, а строки вида `game/…/файл.rpy:12` получают кнопку перехода к нужному блоку.
- Это **новая версия оболочки (1.3)**: чтобы вкладка заработала, один раз скачайте установщик (ссылки выше) и запустите поверх старой версии. Проекты, вход в Google и GitHub сохранятся. Без обновления вкладка просто подскажет, что нужна свежая оболочка.
- Запись собранной игры в папку теперь не перезаписывает неизменившиеся файлы (Ren'Py не перекомпилирует их заново).
- «Я — это…» и авторство блоков (1.2.29), HTML-игра для тестеров (1.2.28), журнал прохождений и тепловая карта (1.2.27), автопрогон (1.2.26), плеер (1.2.25).

**Если программа пишет «нужна обновлённая оболочка»:** один раз скачайте установщик (ссылки выше) и запустите поверх старой версии. Проекты и вход в Google сохранятся.
