## Карта новеллы 1.6.10

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить версию» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Что нового: готовая озвучка возвращается в игру**
- **Вставить voice.** В «Листе для озвучки» новая кнопка «Вставить voice…». Когда записи готовы, перед каждой репликой в скрипте нужна строка `voice "файл"`; раньше её приходилось вписывать руками. Теперь «Загрузить файлы озвучки» берёт много файлов сразу и сопоставляет каждый с репликой по имени из листа (регистр, пробелы и «_» не важны, расширение любое), а записи становятся ресурсами вида «Голос». Ниже виден список: какая строка `voice` в какое место встанет. Кнопка «Вставить» пишет строки перед репликами с тем же отступом (в том числе внутри `menu`). Реплика, чей текст успел измениться, пропускается и называется в уведомлении. Все вставки отменяются одним Ctrl+Z. Пока вы не нажали кнопку, ничего не меняется.
- Работает и для записей, уже лежащих в реестре (в том числе загруженных массовой загрузкой как «Музыка», такие помечены в списке), и для строк `voice`, которые уже есть в скрипте, а файла в реестре нет: запись создаётся под путём из скрипта.
- Урок и справка «Лист для озвучки» дополнены.

**Оболочка не менялась:** отдельно обновлять программу не нужно, хватит кнопки «Обновить версию».

**Честно:** всё проверено автотестами (загрузка, сопоставление имён, вставка, пропуск изменившихся строк, отмена, сборка без предупреждений о неизвестном звуке, английский язык). Сопоставление идёт только по именам из листа: если актёр назвал файл иначе, он останется без пары и будет назван в уведомлении. В настоящем Ren'Py игру с такими строками пока никто не запускал.
