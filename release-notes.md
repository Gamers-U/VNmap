## Карта новеллы 1.7.2

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить версию» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Срочное исправление: программа для компьютера не запускалась после установки**
- **Что было:** в установщик не попадали три файла оболочки (`ai.js`, `projfs.js`, `sat.js`). Установленная программа сразу после запуска показывала окно «A JavaScript error occurred in the main process … Cannot find module './ai'». Ошибка была в списке файлов сборки (он вёлся вручную) и касалась установщиков, начиная с 1.6.17. Автотесты запускали оболочку из папки разработки, где файлы есть, поэтому не заметили. Простите.
- **Что сделано:** в сборку берутся **все** файлы оболочки автоматически (`package.json`, `pack.py`, `install-windows.ps1`). Новая проверка запускает программу из копии, где лежат только файлы сборки, и ещё одна проверка на GitHub смотрит готовый `app.asar` и не даст выпустить неполный пакет.
- **Как исправить у себя:** скачайте установщик этой версии (`VNMap-win-x64-setup.exe` и т. п.) и поставьте поверх: проекты и входы сохранятся. Кнопка «Обновить версию» и «Проверить оболочку» здесь не помогут, потому что программа не стартует.
- **Окно кода в программе со старой оболочкой.** Если установлена старая оболочка (без доступа к папкам), дерево папок писало «доступно в программе для компьютера», хотя вы и были в программе. Теперь там написано, что оболочка старая, и кнопки загрузки свежей версии.

**Всё, что было в 1.7.1 (чат с ИИ в окне кода и «Применить»), остаётся.** Подробности в описании выпуска 1.7.1 в репозитории.

**Честно:** автотесты нового: 14 проверок пакета (в том числе запуск из копии только с файлами сборки; на прежнем списке файлов проверка падает), 5 проверок сообщения о старой оболочке. Установщик под Windows я в этой среде запустить не могу: проверялась та же раскладка файлов под Linux (Electron из копии с файлами сборки). Если после установки что-то ещё не стартует, пришлите скриншот.
