## Карта новеллы 1.2.28

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Что нового**
- **HTML-игра для тестеров** («Инструменты → HTML-игра для тестеров…»): один файл, который тестер открывает в обычном браузере без установки и интернета. Только плеер, без карты и редактора; картинки и звук вкладываются по галочкам. Тестер вводит имя, проходит игру, может оставить «Замечание» к любому месту и в конце сохраняет журнал, который присылает вам. Журнал добавляется в «Журнал прохождений»: тепловая карта и список замечаний.
- Журнал прохождений и тепловая карта (1.2.27), автопрогон и понятные ошибки подключения к GitHub (1.2.26), встроенный плеер (1.2.25).
- Исправлено: в некоторых окнах вместо пустого места могло появляться слово «null».

**Если программа пишет «нужна обновлённая оболочка»:** один раз скачайте установщик (ссылки выше) и запустите поверх старой версии. Проекты и вход в Google сохранятся.
