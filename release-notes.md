## Карта новеллы 1.6.0

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить версию» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Что нового: уведомления в Telegram и Discord (новая оболочка 1.6)**
- «Инструменты → Уведомления». **Telegram:** свой бот у @BotFather, токен вставляете в программу, нажимаете Start у бота, и кнопка «Найти мой чат» сама находит ваш чат. Бот пишет вам в личные сообщения. **Discord:** ссылка вебхука вашего канала (хватит сервера на одного) и по желанию ваш ID, чтобы сообщение вас упоминало.
- **Проект закрыт:** короткая сводка сессии (сколько глав изменено, слов, новых блоков, замечаний, кто из команды что правил). Приходит, если программа была открыта хотя бы минуту. Отправляет сама оболочка в момент закрытия окна, страница для этого не нужна.
- **Сроки задач:** раз в день ваши просроченные и сегодняшние задачи (корпоративный режим). Пока программа открыта.
- **Напоминания на GitHub, когда компьютеры выключены:** вкладка собирает файл-расписание и скрипт для GitHub Actions. Раз в день GitHub сам читает проект из репозитория и пишет каждому участнику его просроченное и сегодняшнее; руководителям ещё и список просроченного по команде. Нужно положить два файла в репозиторий и добавить секрет VNMAP_NOTIFY (по строке на участника; свою строку копирует кнопка). Бесплатно, бот на сервере не нужен.
- Токен бота и ссылка вебхука хранятся только в оболочке, зашифрованными средствами системы. В проект, в настройки страницы и на GitHub они не попадают (в секрет репозитория вы кладёте их сами, осознанно).

**Нужна новая оболочка (линия 1.6):** страница сама не имеет права ходить на Telegram и Discord, это делает оболочка. Поставьте установщик 1.6.0 или обновите программу кнопкой обновления оболочки. Старая оболочка покажет в окне уведомлений, что нужно обновиться. В браузерной версии уведомления недоступны, набор для GitHub можно скачать и там.

**Честно:** проверено на имитации (поддельные Telegram, Discord и GitHub, поддельная оболочка, скрипт запущен в Node). С настоящим Telegram, Discord, Electron и GitHub Actions ещё не пробовалось. Особенно прошу проверить: приходит ли сообщение при закрытии окна, находит ли «Найти мой чат» ваш чат, запускается ли workflow. Если GitHub не даёт записать файл расписания из программы (токену нужно право workflow), скачайте файлы кнопкой и закоммитьте сами.
