## Карта новеллы 1.7.24

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Вход через GitHub App (доступ только к одному репозиторию), подсказка про общий аккаунт Google**
- **Вход через GitHub App.** Программа умеет входить через приложение GitHub, которое владелец устанавливает на один репозиторий новеллы. Участник не даёт доступ «ко всем своим репозиториям» (как у прежнего входа): токен видит только репозиторий, где установлено приложение и к которому у участника есть доступ. В окне входа нет переключателя «Только открытые», есть кнопка «Установить приложение» и подсказка про приглашение в Collaborators. Если приложение не установлено, сообщение так и говорит. Режим включится, когда владелец создаст приложение (пошагово: `claude/github-app.md` в проекте) и в оболочку будут вписаны его Client ID и имя; до этого работает прежний вход, вход токеном вручную остаётся.
- **Токен не слетает.** Если у приложения включено истечение токенов (8 часов), программа сама обновляет токен при первой же ошибке доступа, секрет для этого не нужен.
- **Вошедшим через прежнее приложение** (когда режим включится) программа подскажет выйти и войти заново, чтобы доступ был только к репозиторию новеллы.
- **Исправлено в программе для компьютера:** в сообщении «репозиторий не найден» не показывался список репозиториев, которые токен видит (фильтр запросов не пропускал нужный адрес).
- **Google Диск: подсказка «Работа командой».** В «Настройки → Подключения → Google Диск» складка про один общий аккаунт Google: какой ключ вписать на втором компьютере, в какой аккаунт войти, как открыть общий проект из списка «Проекты на Диске». В «Недостающих файлах» при пустом Диске или без папки проекта есть кнопка «Как подключить второго человека»; тексты про Диск теперь говорят об общем аккаунте.
- Обновление оболочки нужно (меняется вход в GitHub): «Обновить» в программе.
