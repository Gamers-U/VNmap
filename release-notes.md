## Карта новеллы 1.2.25

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Что нового**
- **Встроенный плеер.** Кнопка «Играть» проходит новеллу прямо в программе, без Ren'Py: реплики, выборы с условиями, переменные, jump/call, фоны, спрайты, музыка. Можно начать с любого блока, откатываться назад, включать авто и пропуск, смотреть и менять переменные, видеть закрытые выборы и открытые концовки.
- Если установлена старая оболочка, программа теперь прямо показывает кнопки «Скачать установщик», а не общую ошибку. Ошибка «нет связи с GitHub» подсказывает, что в браузере GitHub заблокирован.
- Справка: новый раздел про плеер.

**Если программа пишет «нужна обновлённая оболочка»:** один раз скачайте установщик (ссылки выше) и запустите поверх старой версии. Проекты и вход в Google сохранятся.
