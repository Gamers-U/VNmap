## Карта новеллы 1.7.20

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить версию» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Подсказки кода везде одинаковые, читаемые в тёмной теме; инструкция по установке Ollama**
- **Автоподстановка в тёмной теме.** Список подсказок раньше рисовался на светлом фоне (фон брался из стандартной светлой темы редактора), а текст оставался светлым: в тёмной теме получался серый текст на белом. Исправлено, то же касается всплывающих окон с ошибками. Проверена читаемость (контраст) в тёмной и светлой темах.
- **Одни и те же подсказки везде, где есть код.** Список имён (метки после `jump`/`call`, картинки и выражения после `scene`/`show`, звуки после `play`, переменные после `$` и `if`, герои в начале строки, трансформы после `at`) теперь работает не только в окне «Редактор кода», но и во вкладке «Скрипт» главы, в «Своём коде» и в «Сниппетах». Имена берутся из проекта (блоки и главы, герои, переменные), из реестра (фоны, спрайты с выражениями, музыка, звуки, трансформы) и из «Своего кода». Окно кода дополнительно видит файлы папки проекта. Внутри кода все три места ведут себя как окно кода: стрелки выбирают, `Enter` или `Tab` вставляют, `Esc` закрывает список.
- **Инструкция по установке Ollama прямо в карточке «Подбор модели».** Пока Ollama не найдена, под карточкой раскрыта пошаговая инструкция для вашей системы (Windows, Mac, Linux; для Linux есть кнопка «Скопировать команду»), рядом подсказка, почему кнопки «Скачать» пока недоступны. Как только вы установите и запустите Ollama, карточка сама заметит это через несколько секунд (каждые 4 секунды тихо проверяет) и включит кнопки.
- Мелочь: в строке «Процессор» теперь «ядер: N» вместо «N ядер» (раньше выходило «2 ядер»).
- Оболочку обновлять не нужно: меняется только страница («Обновить версию»).
