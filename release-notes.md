## Карта новеллы 1.5.3

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить версию» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Что нового: задачи и сроки (корпоративный режим)**
- Работает только когда в «Правах доступа» включён корпоративный режим. В меню «Инструменты» появилось окно «Задачи».
- **У блока** в окне «Обзор» есть «Срок» и «Приоритет». Ставят их владелец и руководители.
- **Отдельные задачи**: название, блок (необязательно), исполнители, срок, приоритет, статус, заметка. Создают и правят задачи владелец и руководители.
- **«Мои»**: ваши задачи и блоки со сроком, сгруппированные по срокам: просрочено, сегодня, на этой неделе, позже, без срока, готово. Статус своей задачи меняете вы сами, чужую менять нельзя. «Открыть блок» переносит на карту.
- **«Все задачи»** с фильтром по человеку (для владельца и руководителей).
- **«Сводка для руководителя»**: сколько открыто, просрочено, готово и без исполнителя; таблица по людям с загрузкой и ближайшим сроком; список просроченного. Блок считается готовым, когда все его файлы в статусе «Готово».
- Задачи и сроки блоков входят в синхронизацию и проверку правок, как остальное содержимое проекта. Защита от чужих правок та же, что в правах: запрещённое откатывается с пояснением.

**Оболочка не менялась** (линия 1.5): обновить достаточно страницу кнопкой «Обновить версию».

**Честно:** проверено на имитации нескольких людей в одном проекте; на настоящем GitHub с несколькими аккаунтами ещё не пробовалось. Все участники должны обновить программу до одной версии.
