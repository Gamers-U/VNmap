**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

**Вход через GitHub App включён: доступ только к репозиторию новеллы**
- В программу вписан Client ID вашего приложения GitHub (`Iv23li7CXZ0zbBsxW6AC`, публичный). Теперь кнопка «Войти через GitHub» (в «Панели GitHub» и на стартовом экране в «Открыть с GitHub…») входит через это приложение: GitHub не просит доступ «ко всем репозиториям». Токен видит только репозиторий, на который приложение установлено, и только если у человека есть к нему доступ (владелец добавляет участников в Collaborators).
- В окне входа больше нет переключателя «Только открытые репозитории»: права задаёт само приложение.
- Кто уже входил раньше (через прежнее приложение с доступом ко всем репозиториям): нажмите «Выйти» и войдите заново. Старый доступ можно отозвать на GitHub: Settings → Applications → Authorized OAuth Apps → Revoke.
