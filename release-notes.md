## Карта новеллы 1.7.26

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

### Что нового
+ История версий: коротко о том, что менялось в каждой версии (Настройки → «Что нового», окно «Обновить», Ctrl+K)
+ В окне «Обновить» перед обновлением видно, что нового в версии, на которую вы обновитесь
+ После обновления при первом запуске всплывает «Версия …: что нового» с кнопкой «Показать»

---
**История версий и «Что нового»**
- Список версий начинается с 1.7.13: у каждой версии отдельные строки «Добавлено», «Изменено», «Исправлено» на языке интерфейса. Окно открывается из «Настроек», из окна «Обновить» и по Ctrl+K («changelog», «что нового»).
- В окне «Обновить» блок «Что нового в версии …» берётся из описания выпуска на GitHub (раздел «### Что нового»). У прежних выпусков без такого раздела показываются первые пункты списка.
- После обновления при первом запуске новой версии один раз всплывает подсказка; на только что установленной программе она не показывается.
- Оболочка не менялась: достаточно обновить страницу.
