## Карта новеллы 1.7.21

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Одна кнопка «Обновить» вместо двух**
- **Всё обновляется одной кнопкой.** В окне «Обновить программу…» (меню или значок внизу) осталась одна кнопка «Обновить». Она сама спрашивает GitHub и про версию (то, что видно в окне), и про оболочку (само окно программы). Если вышла новая оболочка, ставится она: в установщике уже лежит свежая версия, второй шаг не нужен. Если оболочка не менялась, обновляется только версия, оболочка остаётся прежней, окно перезагружается за пару секунд. Кнопок «Обновить версию» и «Обновить оболочку» больше нет.
- **Окно заранее говорит, что сделает кнопка.** При открытии оно само проверяет GitHub и пишет: «Вышла версия …, оболочка в ней не изменилась» или «Вышла версия …, и в ней новая оболочка», как именно она поставится (Windows и Linux ставят сами и перезапускаются), и «У вас всё последнее», если нового нет. Если вы нажали сразу, как увидели описание, лишних вопросов нет; если за это время вышла другая версия, программа спросит перед закрытием.
- **Если оболочка сама себя заменить не может** (версия без установки, macOS): файл оболочки скачивается в «Загрузки» и показывается в папке, а версия страницы обновляется сразу. После перезапуска программа один раз напомнит, что файл лежит в «Загрузках». Если для вашей системы готового файла в выпуске нет, страница всё равно обновится, а для оболочки покажутся ссылки на скачивание.
- **Сбои проверки понятны.** Если GitHub недоступен, окно пишет почему, а не «всё последнее». Если не удалось проверить только оболочку, версия страницы всё равно обновится. Своё поле «владелец/репозиторий» и «Проверять при запуске» остались в том же блоке; «Другие способы: файл или ссылка» и откат без изменений.
- **Исправлена скрытая ошибка при смене оболочки.** Раньше старое обновление версии лежало в папке данных и после установки новой оболочки могло перекрыть более свежую страницу из установщика. Теперь после смены оболочки программа берёт встроенную страницу, если она не старее установленного обновления. Нарочно поставленная старая версия (кнопка «Всё равно установить старую» в «Других способах») остаётся, пока оболочка прежняя.
- Пункт меню называется «Обновить программу…» во всех местах; подсказки про старую оболочку (вход через GitHub, подбор модели) ссылаются на новую кнопку.
- **Оболочку обновить нужно один раз** (изменилась проверка старых версий): обновите версию старыми кнопками как обычно, затем откройте «Обновить программу…» и нажмите «Обновить»: окно само предложит новую оболочку. Дальше всё одной кнопкой.
