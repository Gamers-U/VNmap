## Карта новеллы 1.7.9

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить версию» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).


**Верхняя панель стала тоньше, меню открывается по значку проекта, «Открыть» переехало в «Файл»** (по вашим замечаниям после проверки 1.7.2, пятая часть)
- **Тонкая полоска окна** (Windows и Linux) уменьшена с 26 до 20 пикселей, это около 5 мм вместо 7 мм. Автоскрытия нет: полоска несёт кнопки «свернуть / развернуть / закрыть», без неё окно нечем закрыть.
- **Меню по значку рядом с названием проекта**: «Новый проект», «Открыть…», «Сохранить файл проекта», «Сборка игры…», «Настройки…», «Светлая / тёмная тема», «Язык», «Справка». Значок теперь кнопка, подсвечивается при наведении. Картинку самого значка менять нельзя, она часть бренда.
- **«Инструменты» — один значок** (четыре кубика) во всех режимах, без подписи; название показывается подсказкой при наведении.
- **Кнопки «Открыть» на панели больше нет.** «Открыть…» теперь первым пунктом в меню «Файл» простого режима, в меню по значку проекта и по Ctrl+O в программе. Из «Настройки → Панель» эта кнопка тоже убрана.

**Дальше по вашему списку:** «Расставить узлы» компактно (змейкой) для линейных новелл, панели без наложения и без «залипания» зон, окно блока на весь экран и в отдельное окно, крупнее предпросмотр в GUI-редакторе, справка с метками на экране и «Попробовать на практике».
