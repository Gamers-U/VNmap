## Карта новеллы 1.7.10

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить версию» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).


**Компактная расстановка, панели без наложения, окно блока на весь экран, крупный предпросмотр GUI** (по вашим замечаниям после проверки 1.7.2, шестая часть)
- **«Расставить узлы» → «Компактно» (змейкой).** Длинная линейная новелла больше не вытягивается в одну строку: блоки идут рядами слева направо, затем справа налево. Число блоков в ряду: «Авто» (по форме экрана) или от 3 до 8. Прежний режим по направлению остался.
- **Панели.** Синие зоны примагничивания видны только пока вы тянете панель, поэтому заголовок и поле ввода больше не мешают. Панель, поставленная в центр, не накладывается на панель «вверху по центру». Во время перетаскивания панель следует за курсором и слегка покачивается.
- **Окно блока (двойной щелчок по узлу)** умеет то же, что редактор текста: развернуть на весь экран, не размывать фон («подсмотреть»), вынести в отдельное окно (в программе для компьютера, можно на второй монитор).
- **Редактор GUI.** Предпросмотр заметно крупнее, окно шире, цвета и размеры текста остались одним набором элементов управления: нажали на часть макета, нужный блок настроек показан рядом.
- **Мелочи.** Пояснение в карточке библиотеки сниппетов больше не обрезается. «Проверка сюжета → Переменные в блоках» по умолчанию открывается на вкладке «Главное» и показывает только блоки, где переменная меняется или её значение неоднозначно; полный список по главам: «Все блоки». Кнопки «Текст» и «Тексты» получили новые значки (перо и строки текста).

**Дальше по вашему списку:** справка крупнее и с метками на экране в длинных разделах, «Попробовать на практике» для редактора кода и интерфейса.
