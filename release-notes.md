## Карта новеллы 1.5.0

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить версию» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Что нового: ветки авторов и проверка правок (панель «GitHub»)**
- **Автор** нажимает «Работать в своей ветке (я автор)» или отмечает «Я автор» при подключении проекта: создаётся ветка `author/ваш-логин`, и все его правки уходят только в неё. Основная версия не затрагивается. Кнопка «Забрать правки из основной ветки» подтягивает то, что владелец принял или поправил сам; правки автора остаются.
- **Владелец** открывает «Инструменты → Проверка правок авторов…», выбирает автора и видит изменения по блокам: новый блок с главами, изменённый текст (удалённые строки красным, добавленные зелёным), стрелки, персонажи, переменные, расположение блоков на карте.
- По каждому изменению три кнопки: **Принять** (в проект одним шагом «Отменить»; если то же место правили и вы, правки сливаются), **Вернуть** (в ветку автора добавляется заметка с вашим замечанием на его блок; у автора появится уведомление, у вас правка скрывается) и **Отклонить**. «Принять всё от автора» берёт сразу всё. Неотмеченное остаётся на потом.
- Возвращённое и отклонённое снова появится в списке, только если автор изменит это место ещё раз. Стрелка, принятая к блоку, которого у вас ещё нет, приносит и сам блок.
- Достижения теперь синхронизируются и в живой совместной комнате.

**Оболочка новая (линия 1.5).** Ей разрешено ровно одно новое действие: создать ветку в репозитории (один запрос, больше она ничего не получила). Если вы ставили 1.4.0, обновите оболочку кнопкой «Обновить оболочку»; если нет, установите эту версию. На старой оболочке всё остальное работает, а ветку автора придётся создать на GitHub руками (имя `author/логин`): программа подскажет, как.

**Честно:** проверено на имитации GitHub с двумя «людьми» (владелец и автор), на настоящем GitHub с двумя аккаунтами ещё не пробовалось. Ветка автора создаётся от основной, поэтому у автора должны быть права записи в репозиторий. Если нужно запретить автору писать в основную ветку, это делается в настройках репозитория на GitHub (защита ветки).
