## Карта новеллы 1.7.19

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить версию» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Локальные модели с подбором под ваш компьютер** (только в программе для компьютера)
- В «Настройки → Подключения → ИИ → Локальные» появилась карточка **«Подбор модели под ваш компьютер»**. Программа сама определяет, сколько у вас оперативной памяти, какой процессор и какая видеокарта (сколько у неё видеопамяти), и подсказывает, какая модель потянет ваш компьютер: **«Быстро»** (помещается в видеопамять), **«Медленнее»** или **«Очень медленно»** (пойдёт на процессоре), **«Не потянет»**. Сверху рекомендация: самая сильная модель для кода из тех, что будут работать быстро.
- Кнопка **«Скачать»** загружает модель в Ollama прямо из программы: видно проценты и сколько уже скачано, есть «Отмена» (докачка потом продолжится с того же места). Если закрыть окно, скачивание не прерывается, а после перезапуска страницы программа подхватывает идущую загрузку. Кнопка **«Использовать»** выбирает Ollama и эту модель для помощника.
- Ollama нужно установить самому (кнопка «Установить Ollama» открывает официальную страницу); если она не запущена, карточка так и скажет и предложит «Проверить снова». Ничего не скачивается без вашего нажатия. Названия моделей и размеры в списке ориентировочные, подсказка не гарантия: на слабом компьютере лучше начать с самой лёгкой.
- Для LM Studio те же названия найдите в поиске самой программы.
- **Нужна свежая оболочка** (программа, не только страница): после «Обновить версию» нажмите «Обновить оболочку» один раз или поставьте свежий установщик. В старой оболочке карточка подскажет обновить оболочку.
- Под капотом: оболочка читает железо только для подбора (ничего никуда не отправляется) и ходит к Ollama только на три фиксированных адреса; имя модели проверяется по шаблону.
