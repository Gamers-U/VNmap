## Карта новеллы 1.7.18

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить версию» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Вход в GitHub по коду, без токена** (задача 65, часть про GitHub)
- В «Настройки → Подключения → Панель GitHub» появилась кнопка **«Войти через GitHub»**. Нажимаете: программа показывает короткий код (вида `ABCD-1234`), сама копирует его в буфер и открывает страницу GitHub. Вы вставляете код там, нажимаете «Authorize», и всё: пароль и токен вводить не нужно. Окно показывает код крупно, сколько он ещё действует, кнопки «Открыть страницу GitHub», «Скопировать код» и «Отмена».
- Токен получает и хранит сама оболочка (зашифрованно, если система это умеет); страница программы его не видит, в чат и в файл проекта он не попадает. Выйти и отозвать доступ можно в любой момент: кнопка «Выйти» в окне и на сайте GitHub: Settings → Applications → Authorized OAuth Apps.
- Переключатель «Только открытые репозитории» запрашивает у GitHub меньше прав (`public_repo` вместо `repo`).
- Вход по токену вручную остаётся: он лежит под строкой «Войти по токену вручную» (и это единственный способ в веб-версии в браузере).
- Понятные сообщения, если что-то не вышло: код истёк, вход отклонён, нет связи, GitHub не отвечает, в OAuth-приложении выключен Device Flow.
- **Нужна свежая оболочка** (программа, не только страница): после «Обновить версию» нажмите «Обновить оболочку» один раз или поставьте свежий установщик. В старой оболочке кнопки нет, программа сама подскажет, что обновить.
- Если репозиторий принадлежит организации, которая ограничивает сторонние приложения, владелец организации должен один раз одобрить приложение (Organization settings → Third-party access → OAuth app policy → Approve).
