## Карта новеллы 1.4.0

**Скачать:** Windows — `VNMap-win-x64-setup.exe` (установка) или `VNMap-win-x64-portable.exe` (без установки); macOS — `VNMap-mac-arm64.dmg` (Apple) / `VNMap-mac-x64.dmg` (Intel); Linux — `VNMap-linux-x86_64.AppImage`. Установщик уже содержит последнюю версию, докачивать ничего не нужно.

`vnmap-update-….zip` нужен только кнопке «Обновить версию» внутри программы (ссылка на репозиторий: `https://github.com/Gamers-U/VNmap`).

**Что нового**
- **Две отдельные кнопки обновления** (значок обновления внизу или меню «Обновить программу…»):
  - «Обновить версию» меняет то, что вы видите в окне (карта, редактор, сборка): быстро, без установщика;
  - «Обновить оболочку» меняет саму установленную программу. Windows (установщик) и Linux (AppImage): программа скачает новую версию, проверит контрольную сумму с GitHub, закроется, поставит и откроется снова. Windows portable и macOS: файл скачивается в «Загрузки» и показывается в папке (заменить себя на ходу они не могут, а macOS без платной подписи Apple запрещает это).
  - О выходе новой оболочки программа скажет сама при запуске.
- **Запуск и сборка в настоящем Ren'Py** («Сборка» → вкладка «Запуск в Ren'Py»): укажите папку Ren'Py SDK и папку проекта, который создал лаунчер, и кнопки «Запустить игру» (можно с любого блока), «Проверить (lint)» и «Собрать дистрибутив» делают всё сами. Вывод движка виден в окне, строки с файлом и номером строки ведут к блоку.
- **Галерея CG**: в реестре у фона появился переключатель «Это CG». Такие картинки попадают в готовый экран `cg_gallery` (файл `gallery.rpy`); в окне «Сборка» лежат готовые строки для кнопки в меню игры.
- Запись игры в папку не перезаписывает неизменившиеся файлы и убирает устаревшие вместе с их `.rpyc`.
- Репозиторий для обновлений по умолчанию — `Gamers-U/VNmap`.

**Важно:** это новая версия оболочки (1.4). Её нужно один раз поставить вручную (ссылки выше, поверх старой версии: проекты, вход в Google и GitHub сохранятся). Дальше оболочка обновляется кнопкой.
