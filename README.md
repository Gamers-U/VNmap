# Карта новеллы (VNmap)

Конструктор визуальных новелл: карта сюжета, текст-редактор как в документе, сценарии, ресурсы и компилятор в Ren'Py.
Работает в браузере и как программа для компьютера (проекты в файлах `.vnmap`, хранение на Google Диске и GitHub).

## Установить программу

Откройте раздел **[Releases](../../releases/latest)** и скачайте файл под свою систему:

| Система | Файл | Как запустить |
|---|---|---|
| Windows (установщик) | `VNMap-…-win-x64-setup.exe` | запустить и пройти установку |
| Windows (без установки) | `VNMap-…-win-x64-portable.exe` | запустить двойным щелчком, ничего устанавливать не нужно |
| Linux | `VNMap-…-linux-x64.AppImage` | сделать файл исполняемым и запустить |
| macOS | `VNMap-…-mac-….dmg` | перенести в «Программы»; при первом запуске — правой кнопкой → «Открыть» |

Windows может показать предупреждение SmartScreen: программа пока не подписана сертификатом. «Подробнее» → «Выполнить в любом случае».

## Обновления

В программе откройте «Обновление программы» и вставьте ссылку на этот репозиторий: `https://github.com/Gamers-U/VNmap`.
Программа найдёт в последнем выпуске файл `vnmap-update-….zip`, проверит контрольную сумму и установит страницу, а если что-то
пойдёт не так — сама вернётся на встроенную версию.

Файл `vnmap-update-….zip` заменяет только страницу программы. **Оболочку** (окно, работа с файлами, Google Диск, GitHub) он не меняет:
если программа пишет «для работы с GitHub нужна обновлённая оболочка», один раз скачайте и запустите свежую версию из Releases.

## Собрать из исходников

```
python3 build.py              # собирает dist/vnmap.html, dist/vnmap-update-….zip и desktop/app/index.html
cd desktop
npm install
npm start                     # запуск в окне
npm run dist:win              # установщики (то же: dist:mac, dist:linux) → desktop/release/
python3 pack.py               # портативные Windows/Linux без npm → desktop/release-portable/
```

Подробнее — в [desktop/README.md](desktop/README.md). Исходники страницы лежат в `src/`, оболочка (Electron) — в `desktop/`.

## Как выпустить новую версию

1. Поменяйте версию в `desktop/package.json`, если менялась оболочка.
2. `git tag v1.2.1 && git push --tags` — или Actions → «Релиз» → Run workflow (тег вводится вручную).
3. Автосборка (`.github/workflows/release.yml`) соберёт страницу, установщики для Windows, Linux и macOS и выложит их в Releases вместе с `vnmap-update-….zip`.

Необязательно: чтобы пользователям не приходилось заводить собственный ключ Google, положите содержимое файла
`google-oauth.json` (образец: `desktop/google-oauth.example.json`) в секрет репозитория `GOOGLE_OAUTH_JSON` — сборка вложит его в программу.
